# Écouter · Niveau B1

Activités de compréhension de l'oral (FLE, niveau B1) à partir de courtes vidéos authentiques.
Pages optimisées pour téléphone, tablette et ordinateur ; fond blanc, couleurs de la Francophonie en accents.

## Structure de chaque activité

1. **Avant la vidéo** : hypothèses, vocabulaire.
2. **Écouter** : écoute générale, écoute détaillée (chiffres, vrai/faux, détails), puis la langue du reportage.
3. **Après la vidéo** : production orale (dont médiation) et production écrite (à rédiger hors de la page).

Les sous-titres incrustés peuvent être masqués pendant les écoutes 1 et 2 (bouton sous la vidéo).

## Fichiers

| Fichier | Contenu |
|---|---|
| `index.html` | Accueil : liste des vidéos |
| `haussmann.html` | Vidéo 1 : « Haussmann transforme le visage de Paris » (Public Sénat, 2 min 24) |
| `haussman.mp4` | La vidéo 1 |
| `assets/style.css` | Style commun |
| `assets/exercices.js` | Exercices autocorrigés (QCM, vrai/faux, ordre, saisie, conjugaison) |

## Ajouter une vidéo

Copier `haussmann.html`, remplacer la vidéo, les exercices et la transcription, puis ajouter une carte dans `index.html`.
Les fichiers vidéo doivent faire moins de 100 Mo (limite de GitHub) ; moins de 25 Mo pour les téléverser depuis le site ou l'application.

## Publier

Settings → Pages → « Deploy from a branch », branche `main`, dossier `/ (root)`.
